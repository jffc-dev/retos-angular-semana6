Template-driven vs Reactive Forms

Mismo formulario (nombre + email), construido de las dos formas. La diferencia está en dónde vive la fuente de verdad: el HTML o el TypeScript.

Template-driven (ngModel)

{{ {nombre: nombre(), email: email()} | json}}

{{ templateForm.valid }}

Reactive Forms (FormGroup)

{{ miFormulario.value | json}}

{{ miFormulario.valid }}
