Estado del control

Cada FormControl trae banderas de estado que Angular actualiza solo. Escribe y luego haz click fuera del input para ver cómo cambian.

pristine / dirty untouched / touched valid / invalid

La condición del mensaje de error es invalid && touched: así no se muestra "obligatorio" apenas carga la página, solo después de que el usuario interactuó con el campo.
